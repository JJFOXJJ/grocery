Watchlist

Prices are polled daily from each store's own site and are best-effort — Woolworths and Coles run bot-detection that can block automated checks on any given day, and Aldi has no public per-item price API in Australia, so its prices are entered manually. Always confirm the final price in-store or at checkout. See README.md for how to edit the watchlist.

GitHub connection

Needed only for the Update prices now button and the Add item form — the rest of the dashboard works with no token. The token is stored solely in this browser's localStorage and sent only to api.github.com; it's never written to the repo or seen by anyone else. Use a token scoped to just this repo: fine-grained PAT with Contents: Read and write and Actions: Read and write on JJFOXJJ/grocery — or a classic PAT with repo + workflow scopes.
